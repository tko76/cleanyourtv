# Chromecast with Google TV 4K, Workshop (device sabrina, product sabrina_prod_stable), Wi-Fi
# Google TV 14 (SDK 34), build UTTC.250917.004 (14193937)
#
# Apply:   TV_HOST=10.44.0.88 tools/disable.sh debloat-chromecast-workshop.txt
# Undo:    TV_HOST=10.44.0.88 tools/restore.sh debloat-chromecast-workshop.txt com.google.android.apps.tv.launcherx
#
# Full launcher takeover chosen (not debloat-keep-cast.txt): phone casting stops working once
# setupwraith is disabled, because it holds the Cast receiver's device credentials
# (examples/google-chromecast-gtv-4k/debloat.txt has the full quirk and the per-boot credential
# workaround, not applied here by choice).
#
# On Wi-Fi: every saved network belonged to setupwraith before this was applied. Forgot the network and
# rejoined it in Settings > Network & Internet first, so every cname read android.uid.system:1000
# (checked with `dumpsys wifi | grep -o 'cname=[^ ]*'`) before setupwraith went in this list.
# No FORCE_SETUPWRAITH: disable.sh's own Wi-Fi-ownership check is left on for this device.
#
# launcher's Clock screensaver set first (settings put secure screensaver_components
# com.gathin.tvhome/.ClockDream), so disabling dreamx/backdrop doesn't leave the screensaver pointing
# at nothing.
#
# No Live TV app and no HDMI inputs (it's a dongle): live_tv_package stays empty.
# Kept on purpose: Google Assistant (com.google.android.katniss), phone remote
# (com.google.android.tv.remote.service), Play Store/Play Services, Gboard, Bluetooth,
# com.google.android.tv.dfuservice (remote firmware updates), the already-sideloaded apps
# (com.player.janky, com.esaba.downloader, ar.tvplayer.tv, nuvio, smarttube).
# com.google.android.apps.education.cast2class and com.google.android.tvrecommendations ship
# factory-disabled; not listed here (pm disable-user on them fails with "Shell cannot change
# component state").
